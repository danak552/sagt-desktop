# Security Policy

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Report security issues to: **hej@sagt.ai**

We aim to respond within 48 hours and will coordinate a fix before any public disclosure.

## Scope

- The desktop application (Tauri v2, this repository)
- The sagt.ai web service (sagt.ai)

## What to include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes (optional)

## Supported versions

Only the latest release receives security fixes. We recommend always running the current version — the app auto-updates via the built-in updater.
